📘 事例Ⅳ 直前総点検ファイナルペーパー（超高密度・完全武装シート）

📌 【最重要】過去10年の盲点公式＆計算ロジック（知らんと即死の12大定理）

1. 企業価値・現在価値・配当割引モデル

  • 永久年金の現在価値: $$\text{現在価値}(PV) = \frac{\text{毎年のキャッシュフロー}(CF)}{\text{割引率}(r)}$$ ※一定のCFが永久に続くと仮定する場合（継続価値・ターミナルバリューの基礎）。
  • 定率成長モデル（ゴードン成長モデル）: $$PV = \frac{CF_1}{r - g} = \frac{CF_0 \times (1 + g)}{r - g}$$ ※CFが毎年一定率 $g$ で永久成長する場合。$r > g$ が必須条件。分母は「資本コスト $-$ 成長率」。
  • フリーキャッシュフロー（FCF）の定義式: $$\text{FCF} = \text{営業利益} \times (1 - \text{税率 } t) + \text{減価償却費} - \text{設備投資} - \Delta\text{運転資本}$$ ※「営業CF $-$ 投資CF」の実務簡便型。支払利息や受取利息などの財務活動は除外する。
  • WACC（加重平均資本コスト）: $$WACC = r_e \times \frac{E}{D+E} + r_d \times (1 - t) \times \frac{D}{D+E}$$ ※負債コスト $r_d$ にのみ「$(1 - t)$（節税効果）」を掛ける。株主資本コスト $r_e$ には絶対に掛けない！
  • CAPM（資本資産評価モデル）: $$r_e = r_f + \beta \times (r_m - r_f)$$ ※$r_f$: 安全資産利子率、$r_m$: 市場期待収益率、$(r_m - r_f)$: マーケット・リスクプレミアム。

2. 取替投資（設備更新）差額キャッシュフローの黄金マトリクス（令和3年猛反省論点）

取替投資は「新設備を導入した世界線」と「旧設備を継続使用した世界線」の【差額（増分CF）】で計算する！ 頭の中だけで解かず、必ず下書き用紙に以下の2列マトリクスを書くこと：

項目 ① 新設備導入案 ② 旧設備継続案 差額（① − ②：増分CF）
0年目初期投資 新設備の取得原価（支出） 0 − 新設備取得原価 ＋ 旧設備売却時CF
現金営業利益 新設備の現金利益 旧設備の現金利益 差額現金営業利益 $\times (1 - t)$
減価償却費 新設備の年間償却費 旧設備の年間償却費 【差額減価償却費】$\times t$ （※超頻出罠！）
旧設備売却損益 期首に旧設備を売却 なし（継続使用） $(\text{旧設備簿価} - \text{売却価額}) \times t$ （※売却損なら＋）

[!WARNING] 【知らんと即死の取替投資トラップ】 1. 差額減価償却タックスシールド: 新設備の減価償却費丸ごとに税率を掛けてはならない！旧設備を使い続けても得られていた減価償却費を差し引いた差額（$1,500\text{万円}$ 等）に対して税率30%（$450\text{万円}$）を計上すること！ 2. 売却損タックスシールド: 「簿価 $>$ 売却額」のとき、売却損により税金が安くなるため必ず初年度CFにキャッシュイン（プラス）として加算する！

3. CVP・営業レバレッジ・段階的価格変動モデル

  • 営業レバレッジ（DOL: Degree of Operating Leverage）: $$DOL = \frac{\text{限界利益}}{\text{営業利益}} = \frac{\text{売上高} - \text{変動費}}{\text{売上高} - \text{変動費} - \text{固定費}} = \frac{1}{\text{安全余裕率}}$$
  • 解釈: 固定費比率が高い企業ほどDOLが大きくなり、売上増加時の利益増大効果が高い反面、減収時の赤字リスクが高い（ハイリスク・ハイリターン構造）。
  • 安全余裕率と損益分岐点比率: $$\text{安全余裕率} = \frac{\text{売上高} - \text{損益分岐点売上高}}{\text{売上高}} \times 100\% = 1 - \text{損益分岐点比率}$$
  • 目標営業利益を達成する売上高: $$\text{目標売上高} = \frac{\text{固定費} + \text{目標営業利益}}{\text{限界利益率}}$$ ※「税引後当期純利益」が指定された場合は、$\text{目標営業利益} = \frac{\text{目標純利益}}{1 - t}$ で税引前に戻してから分子に足す！
  • 階段型価格変動モデルの判定ルール（令和3年第3問完答の神技）:
  • 注記を確認：「販売数量全体に該当区分の単価が適用（全体適用型）」か、「超過分のみに適用（超過累進型）」か。
  • 境界値（2万kg、3万kg等）を代入して利益を検算し、目標利益がどのステージに属するかを特定してから方程式を解く。
  • 端数処理指示が「切り上げ」なら、1kgでも端数が出たら切り上げる（例: $38,571.42 \to \mathbf{38,572\text{kg}}$）。

4. 制約条件下の最適セールスミックス（令和4年・令和7年頻出）

  • 判定基準: 「製品単価」や「製品1個あたり限界利益」ではなく、【制約条件1単位あたりの限界利益】が高い順に優先生産する！ $$\text{優先度} = \frac{\text{製品1個あたり限界利益}}{\text{製品1個あたり制約資源使用量（機械時間・職人作業時間など）}}$$
  • 手順:
  • 優先順位第1位の製品を需要上限まで全量生産する。
  • 残余の制約資源（残り時間など）を、優先順位第2位の製品に投入する。
  • 固定費は埋没原価として扱い、セールスミックスの順位付けには一切影響させない。

5. 付加価値額・生産性指標（H29・R1頻出）

  • 中小企業庁方式（加算法）★最頻出: $$\text{付加価値額} = \text{営業利益} + \text{人件費} + \text{減価償却費}$$ ※問題文に賃借料や租税公課等の指示があれば加算する。
  • 日銀方式（控除法）: $$\text{付加価値額} = \text{売上高} - \text{外部購入価値（材料費・外注費・仕入原価など）}$$
  • 労働生産性（2分解公式）: $$\text{労働生産性} = \frac{\text{付加価値額}}{\text{従業員数}} = \frac{\text{売上高}}{\text{従業員数}} \times \frac{\text{付加価値額}}{\text{売上高（付加価値率）}}$$
  • 労働分配率: $$\text{労働分配率} = \frac{\text{人件費}}{\text{付加価値額}} \times 100\%$$

6. 経営分析・財務比率の盲点と単位即死トラップ防止表

指標名 計算公式 単位 判定基準・意味
棚卸資産回転率 $\text{売上高} \div \text{棚卸資産}$ 回 高いほど鮮度管理・在庫効率が良好（生鮮スーパー等）
売上債権回転期間 $\text{売上債権} \div (\text{売上高} / 365)$ 日（月） 短いほど売掛金の回収が速く資金繰りが健全
負債比率 $\text{負債合計} \div \text{自己資本（純資産）} \times 100$ ％ 100%以下が健全。400%超は過大な借入金リスク
当座比率 $\text{当座資産} \div \text{流動負債} \times 100$ ％ 100%以上が望ましい。棚卸資産を除いた超短期支払能力
固定長期適合率 $\text{固定資産} \div (\text{自己資本} + \text{固定負債}) \times 100$ ％ 100%以下が必須。固定資産を長期安定資金で賄えているか
インタレスト・カバレッジ $(\text{営業利益} + \text{受取利息配当金}) \div \text{支払利息}$ 倍 1.0倍未満は営業利益で利息すら払えない危険水準
所要運転資金 $\text{売上債権} + \text{棚卸資産} - \text{仕入債務}$ 円/千円 売上急増時にこれが膨らむと「黒字倒産」の危機

[!CAUTION] 【単位の即死トラップ】 - 回転率の欄に「％」と書いたら一発ゼロ点！必ず「回」と書く。 - 回転期間の欄には「日」または「ヶ月」（問題文指定に従う）。 - 金額単位は「円」「千円」「百万円」を絶対に問題文と見比べること！
