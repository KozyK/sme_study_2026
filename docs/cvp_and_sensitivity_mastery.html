📘 事例Ⅳ CVP分析・感応度分析・最適セールスミックス完全攻略

🎧 AUDIO OVERVIEW この資料の対話型ポッドキャスト解説

〜損益分岐点・目標利益逆算・営業レバレッジ・多品種CVPの解法アルゴリズム〜

はじめに：なぜCVP分析で計算ミスや時間オーバーが頻発するのか？

事例Ⅳの第2問または第3問において、設備投資NPVと並んで毎年確実に出題されるのが「CVP（Cost-Volume-Profit：原価・営業量・利益）分析」です。

一見すると「$S = \frac{FC}{1 - \alpha}$」という単純な公式の当てはめに思えますが、本番の試験では以下のような罠が張り巡らされており、多くの受験生が手痛い失点を喫します。

  1. 税引後利益目標の罠: 「税引前」なのか「税引後」なのかを見落とし、税引後利益を法人税率で割り戻さずに計算してしまう。
  2. 多品種CVPの加重平均限界利益率: 各製品の売上構成比を考慮せず、単純平均してしまう。
  3. 安全余裕率と営業レバレッジの相互連動: 売上変動が利益に与えるインパクトを論理的に説明できない。
  4. 固定費削減と変動費率低減の感応度の違い: 経営改善策としてどちらを優先すべきかの判断がつかない。

本書では、これらの頻出論点を公式の丸暗記ではなく、「利益構造の数理的メカニズム」として論理的に解剖し、電卓の最小打鍵数で完答するための思考アルゴリズムを伝授します。

第1章：CVPの基本構造と重要公式の変形

1. 損益計算書の数理モデル

［売上高：S］
  −［変動費：V ＝ α × S］  （α：変動費率）
  ＝【限界利益：MP ＝ m × S】 （m：限界利益率 ＝ 1 − α）
  −［固定費：FC］
  ＝【営業利益：OP】

この基本関係から、営業利益 $OP$ は以下のように表されます。

$$OP = S \times (1 - \alpha) - FC = m \times S - FC$$

2. 損益分岐点売上高（Break-Even Point, BEP）

営業利益がちょうどゼロ（$OP = 0$）になる売上高 $S^*$ は、限界利益が固定費と完全に一致する点です。

$$S^* = \frac{FC}{1 - \alpha} = \frac{FC}{m}$$

  • 損益分岐点比率: $\frac{S^*}{S} \times 100\%$（低いほど不況抵抗力が高く安全。中小企業では80%以下が優良の目安）。
  • 安全余裕率（経営安全率, MOS）: 実際の売上高が損益分岐点をどれだけ上回っているかを示す指標。

$$\text{安全余裕率（MOS）} = \frac{S - S^*}{S} = 1 - \text{損益分岐点比率}$$

3. 目標利益を達成するための必要売上高（税引前 vs 税引後）

パターンA：目標営業利益（税引前）が指定された場合

目標利益を「回収すべき固定費の上乗せ」とみなします。

$$S = \frac{FC + OP_{\text{target}}}{1 - \alpha}$$

パターンB：目標当期純利益（税引後利益）が指定された場合 ★超頻出トラップ！

税引後利益 $NP_{\text{target}}$ を達成するには、法人税（実効税率 $t$）が引かれる前の「税引前目標利益」に割り戻さなければなりません。

$$\text{必要税引前利益} = \frac{NP_{\text{target}}}{1 - t}$$

したがって、必要売上高の計算式は以下のようになります。

$$S = \frac{FC + \frac{NP_{\text{target}}}{1 - t}}{1 - \alpha}$$

【注意】
問題文に「当期純利益○○百万円を達成するための売上高を求めよ（法人税率30%）」とあったら、分子に足す利益は必ず「$NP \div (1 - 0.3)$」とします。これを忘れると連鎖的に大失点します。

第2章：安全余裕率と営業レバレッジ係数（DOL）の黄金定理

1. 営業レバレッジ係数（Degree of Operating Leverage, DOL）とは？

営業レバレッジ係数とは、「売上高が1%変化したときに、営業利益が何%変化するか」という感応度（増幅率）を表す指標です。

$$\text{DOL} = \frac{\text{営業利益の変化率（}\Delta OP / OP\text{）}}{\text{売上高の変化率（}\Delta S / S\text{）}} = \frac{\text{限界利益（}MP\text{）}}{\text{営業利益（}OP\text{）}} = \frac{S - V}{S - V - FC}$$

  • 固定費が重い企業: 限界利益に対して営業利益が小さいため、DOLが極めて高くなります（ハイリスク・ハイリターン構造）。売上が少し伸びるだけで利益が爆発的に増えますが、売上が少し落ちると一気に赤字に転落します。
  • 固定費が軽い企業（変動費中心）: DOLが低く、売上の増減による利益のブレが小さくなります（ローリスク・ローリターン構造）。

2. 試験で武器になる「黄金定理」

安全余裕率（MOS）と営業レバレッジ係数（DOL）には、驚くべき数学的関係が存在します。

$$\mathbf{DOL = \frac{1}{\text{安全余裕率（MOS）}}}$$

証明

$$\text{MOS} = \frac{S - S^*}{S} = \frac{S - \frac{FC}{m}}{S} = \frac{m S - FC}{m S} = \frac{OP}{MP}$$ 分子と分母をひっくり返すと、まさに $\frac{MP}{OP} = DOL$ となります。

この定理がもたらす超高速判断

  • 安全余裕率が 20%（0.2） の企業：
    営業レバレッジは $\frac{1}{0.2} = \mathbf{5 \text{ 倍}}$！
    $\implies$ 売上高が 10% 増加 すれば、営業利益は $10\% \times 5 = \mathbf{50\% \text{ も激増}}$ する！
    $\implies$ 逆に売上高が 10% 減少 すれば、営業利益は 50% 激減 する！
  • 電卓を叩いて複雑な利益再計算をしなくても、売上変動に伴う利益の変動額や増減率が瞬時に把握できます。

第3章：多品種製品のCVP分析（加重平均限界利益率）

複数の製品（A製品、B製品、C製品など）を販売している企業では、製品ごとに販売単価も変動費率も異なります。この場合、「各製品の売上高構成比が今後も一定である」という仮定のもとでCVP分析を行います。

1. 加重平均限界利益率（$\bar{m}$）の算出アルゴリズム

各製品の限界利益率（$m_i$）に、売上高構成比（$w_i = \frac{S_i}{S_{\text{total}}}$）を掛け合わせて合算します。

$$\bar{m} = \sum_{i} (w_i \times m_i) = w_A m_A + w_B m_B + w_C m_C$$

または、全社の限界利益の合計を全社売上高の合計で割っても同じです。

$$\bar{m} = \frac{\text{全社限界利益合計}}{\text{全社売上高合計}}$$

2. 全社および製品別の損益分岐点売上高

  1. 全社の損益分岐点売上高: $$S^*_{\text{total}} = \frac{\text{全社固定費}}{\bar{m}}$$
  2. 各製品の損益分岐点売上高: 全社損益分岐点売上高に、それぞれの売上高構成比を掛けます。 $$S^_A = S^{\text{total}} \times w_A, \quad S^_B = S^{\text{total}} \times w_B$$

3. セールスミックス変化の影響

  • 限界利益率の高い製品の構成比が上がると $\implies$ 全社加重平均限界利益率が上昇 $\implies$ 全社の損益分岐点売上高は低下（改善）する。
  • 限界利益率の低い製品の安売りで売上を伸ばしても $\implies$ 加重平均限界利益率が悪化 $\implies$ 損益分岐点が押し上げられ、収益構造が脆くなる。

第4章：感応度分析（固定費削減 vs 変動費率引き下げ）

経営改善策として「固定費を減らす（省人化・賃料見直し等）」と「変動費率を下げる（歩留まり改善・仕入単価交渉等）」のどちらが損益分岐点をより大きく引き下げるかを比較・分析させる問題です。

比較シミュレーションの定石

改善策 損益分岐点への影響の出方 メリット デメリット・リスク
固定費の削減（$\Delta FC$） 損益分岐点売上高が「$\frac{\Delta FC}{m}$」だけ直接的に引き下がる。売上高の大小にかかわらず均等に効く。 操業度が落ちても確実に効果が出る。低操業度期に強い。 設備の廃棄や人員削減を伴う場合、将来の拡大期に対応できなくなるリスク。
変動費率の引き下げ（$\Delta \alpha$） 限界利益率 $m$ が拡大するため、売上高が大きくなればなるほど利益押し上げ効果が指数関数的に増大する。 操業度が高く売上高が大きい企業ほど絶大な効果を発揮する。 売上が減少した局面では効果が限定的になる。

第5章：耳で解く！CVP実践計算ドリル

ドリル1：目標税引後利益の逆算

  • 条件:
  • 固定費：600万円
  • 変動費率：60%（限界利益率：40%）
  • 法人税率：30%
  • 目標当期純利益：140万円
  • 解答プロセス:
  • 必要税引前利益を算出: $$\text{税引前利益} = \frac{140 \text{ 万円}}{1 - 0.30} = \mathbf{200 \text{ 万円}}$$
  • 必要売上高を算出: $$S = \frac{600 + 200}{0.40} = \frac{800}{0.40} = \mathbf{2,000 \text{ 万円}}$$
  • 検算：売上2,000万 $\times$ 40% ＝ 限界利益800万。固定費600万を引いて営業利益200万。税金30%（60万）引いて純利益140万。完璧！

ドリル2：安全余裕率と営業レバレッジの換算

  • 条件: 売上高1億円、損益分岐点売上高8,000万円。売上が15%増加した場合、営業利益は何%増加するか？
  • 解答プロセス:
  • 安全余裕率を算出: $$\text{MOS} = \frac{10,000 - 8,000}{10,000} = \mathbf{20\% (0.20)}$$
  • 営業レバレッジ係数（DOL）を黄金定理で即答: $$\text{DOL} = \frac{1}{0.20} = \mathbf{5 \text{ 倍}}$$
  • 利益増加率を算出: $$15\% \times 5 = \mathbf{75\% \text{ 増加}}$$

まとめ：CVP分析を制する鉄則

  1. 「当期純利益」という言葉を見たら、直ちに「$(1 - t)$」で割り戻して税引前利益に変換する。
  2. 多品種CVPは、売上高構成比による「加重平均限界利益率」を真っ先に確定する。
  3. 安全余裕率と営業レバレッジは逆数の関係（$\text{DOL} = 1 / \text{MOS}$）であることをフル活用して、売上変動のインパクトを論理的に説明する。
