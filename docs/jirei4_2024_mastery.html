はじめに：令和6年度 事例Ⅳの全体構造と「解けなかった」の真相

令和6年度の事例Ⅳを解き終えた直後、多くの受験生が「難しかった」「時間が足りず、ほぼ解けなかった」という強い挫折感に苛まれました。 しかし、コウジさんの答案を客観的な採点基準に照らし合わせて分析すると、全く異なる事実が浮かび上がってきます。

コウジさんは、着手した約55点分の問題に対して37点（得点率約67%）を獲得しており、これは中小企業診断士2次試験の合格基準（60%）を上回るペースです。 特に、事例Ⅳの最大の土台である第1問（経営分析）では、3つの指標名・数値・端数処理すべて完全一致、記述も因果関係が完璧で「24点 / 25点（得点率96%）」という、全国トップクラスのスコアを叩き出しています。

では、なぜ「ほぼ解けなかった」と感じてしまったのか？ その真の原因は、実力不足ではなく「第1問で30分消費してしまったことによる、後半の構造的なタイムアウト」にあります。

本書では、コウジさんの答案の優れた強みを再確認しつつ、失点した論点（線形計画法の端点判定、取替投資のNPV・キャッシュフロー計算、管理会計の振替価格）の解法を根本から解剖し、事例Ⅳで確実に60点〜70点台を突破するための思考体系とタイムマネジメント技術を徹底的に伝授します。

第1問：経営分析（配点25点） ⇒ 【コウジさんの獲得点：24点】

1. 設問の意図と出題者の狙い

  • 出題趣旨: 財務諸表を分析し、診断・助言の基礎となる財務指標を的確に導出する能力と、その背景にある経営実態を構造的に把握する能力を問う。

2. コウジさんの答案検証と高得点の理由

  • 設問1（指標算出：15点満点）:
  • ① 優れている指標：有形固定資産回転率 11.26回（同業他社：6.74回） $\implies$ 5点満点
  • ② 劣っている指標1：売上高営業利益率 1.01%（同業他社：4.22%） $\implies$ 5点満点
  • ③ 劣っている指標2：負債比率 606.94%（同業他社：180.35%） $\implies$ 5点満点
  • 設問2（特徴記述：9点 / 10点）:

    製品開発から販売に至る一貫体制により効率性は高いが、一貫体制の構築維持コストで財務安全性が低く、競争激化とともに収益性悪化の要因となっている。（72字）

  • 講評:
  • 効率性（有形固定資産回転率）、安全性（負債比率）、収益性（売上高営業利益率）の3指標について、与件文に明記された事業背景（一貫体制の構築・維持、市場の競争激化）と完璧に紐づけられており、文句なしの答案です。

3. 課題：なぜ「30分」かかってしまったのか？

コウジさんが30分を費やした理由は、答案の精度の高さが証明している通り、「慎重に指標を比較吟味し、検算と記述の推敲を極めて丁寧に行ったこと」にあります。 しかし、事例Ⅳの制限時間は80分です。第1問に30分使うと、残り50分で第2問・第3問・第4問を処理しなければならず、1問あたり16分しか残りません。

4. 深掘り講義：経営分析を「15分〜20分」で完答する超高速ルーティン

精度を95%維持したまま所要時間を15分に短縮するための「3つの技術」をマスターしましょう。

① 財務諸表の「目視アタリ付け」法（計算は5つ以内に絞る）

P/LとB/Sの全項目を片っ端から電卓で割っていくと、それだけで10分を消費します。 計算する前に、以下の「3つの視点」で目視比較を行います。

財務の領域 目視で確認する勘定科目 D社と同業他社の違い アタリをつける指標候補
収益性 売上高に対する売上原価、販管費、営業利益の大きさ D社の営業利益（3,100万円）は同業他社に比べて著しく低い 売上高営業利益率（または売上高総利益率）
効率性 有形固定資産と売上高のバランス D社は有形固定資産が740百万円と小さい割に売上が大きい 有形固定資産回転率（または棚卸資産回転率）
安全性 純資産（432百万円）と負債合計（2,622百万円）の比率 純資産が極端に薄く、長期借入金が重い 負債比率（または自己資本比率）

この目視確認を最初の2分で行うことで、計算対象を「有形固定資産回転率」「売上高営業利益率」「負債比率」「自己資本比率」の4つだけに絞り込み、電卓を叩く時間を劇的に削減します。

記述に悩む時間をゼロにするため、以下の構文に数字と与件の言葉を流し込みます。

第2問：線形計画法・セールスミックス（配点20点） ⇒ 【コウジさんの獲得点：5点】

1. 設問の意図と出題者の狙い

  • 設問1（12点）: 直接作業時間と機械稼働時間の制約下で、製品Xおよび製品Yの最適生産数量と最大営業利益を算出する。
  • 設問2（8点）: Y社向け最低販売数量（2,400袋）の制約が加わった場合、現行の営業利益を下回らないためのY社の最低販売単価を逆算する。

2. コウジさんの答案検証

  • 設問1の解答:
  • X社向け数量：3,600 袋
  • Y社向け数量：2,560 袋
  • 営業利益：2,427,200 円
  • 計算過程:
  • 不等式制約：$x \le 6500, y \le 4200, x + 2.5y \le 10000, 2x + 2.5y \le 13600$
  • 単位あたり限界利益：X＝1,220円、Y＝1,420円
  • 目的関数：$f(x, y) = 1220x + 1420y - 5,600,000$
  • 交点連立方程式：$x + 2.5y = 10000$ と $2x + 2.5y = 13600$ を解き、$x = 3600, y = 2560$ を導出。
  • 講評:
  • 数式モデルの構築（定式化）は満点です。
  • 2つの制約線の交点を求める連立方程式の計算も完全に正確でした。
  • しかし、最適解は交点 $(3600, 2560)$ ではなく、端点である $(6500, 240)$ でした。定式化と限界利益の算出プロセスの部分点として5点が付与されます。

3. 深掘り講義：なぜ交点ではなく「端点 (6500, 240)」なのか？

線形計画法において、多くの受験生が「制約条件の連立方程式を解いて得られる交点が最適解である」と思い込んでしまいます。しかし、これは重大な盲点です。

① 実行可能領域の頂点比較

線形計画法の最適解は、実行可能領域のいずれかの頂点（端点）に必ず存在します。 今回の制約を満たす領域の頂点における利益を比較してみます。

頂点の座標 $(x, y)$ 限界利益合計（円） 固定費（円） 営業利益（円） 判定
$(0, 4000)$ $1420 \times 4000 = 5,680,000$ 5,600,000 80,000 最低
$(3600, 2560)$（コウジさんの解） $1220 \times 3600 + 1420 \times 2560 = 8,027,200$ 5,600,000 2,427,200 良好だが最適ではない
$(6500, 240)$（真の最適解） $1220 \times 6500 + 1420 \times 240 = \mathbf{8,270,800}$ 5,600,000 2,670,800 最大（最適解！）
$(6500, 0)$ $1220 \times 6500 = 7,930,000$ 5,600,000 2,330,000 -

頂点 $(6500, 240)$ の営業利益は $2,670,800$ 円であり、交点 $(3600, 2560)$ の利益（$2,427,200$ 円）よりも 243,600円も高くなります。

② グラフを描かずに3分で最適解を見抜く「ボトルネック限界利益」解法

この端点判定を、グラフを描かずに瞬時に見抜く決定的な解法が「制約資源1単位あたりの限界利益の比較」です。

  1. 2つの制約条件の確認:
  2. 直接作業時間：$1.0x + 2.5y \le 10,000$ 時間
  3. 機械稼働時間：$2.0x + 2.5y \le 13,600$ 時間
  4. 機械稼働時間1時間あたりの限界利益を比較する:
  5. 製品X：$1,220 \text{ 円} \div 2.0 \text{ 時間} = \mathbf{610 \text{ 円/時間}}$
  6. 製品Y：$1,420 \text{ 円} \div 2.5 \text{ 時間} = \mathbf{568 \text{ 円/時間}}$
  7. $\implies$ 製品Xの方が、機械を1時間動かしたときに稼げる限界利益が大きい（$610 > 568$）！
  8. 意思決定のルール:
  9. より効率よく稼げる製品Xを、市場需要の上限（$6,500$ 袋）まで最優先でフル生産する。
  10. 残った機械稼働時間をすべて製品Yの生産に充てる。
  11. 数量の計算:
  12. Xを $6,500$ 袋生産するのに必要な機械時間：$6,500 \times 2.0 = 13,000$ 時間。
  13. 余った機械稼働時間：$13,600 - 13,000 = 600$ 時間。
  14. この $600$ 時間で生産できる製品Yの数量：$600 \div 2.5 = \mathbf{240 \text{ 袋}}$。
  15. 直接作業時間の充足確認：$6,500 \times 1.0 + 240 \times 2.5 = 6,500 + 600 = 7,100 \le 10,000$ 時間（余裕あり）。
  16. 結論:
  17. 最適生産数量：$X = 6,500$ 袋、$Y = 240$ 袋。
  18. 営業利益：$1,220 \times 6,500 + 1,420 \times 240 - 5,600,000 = \mathbf{2,670,800 \text{ 円}}$。

この「ボトルネック1単位あたり限界利益」の原則を知っていれば、複雑なグラフや連立方程式を一切解くことなく、電卓を数回叩くだけで3分で満点が取れます。

4. 設問2：機会原価と最低販売単価の導出

設問2は「Y社から最低2,400袋を要求された場合、現行の営業利益（2,670,800円）を下回らないためのY社の販売価格」を求める問題です。

  • 思考プロセス:
  • Y社を2,400袋作るために必要な機械時間：$2,400 \times 2.5 = 6,000$ 時間。
  • 残りの機械稼働時間：$13,600 - 6,000 = 7,600$ 時間。
  • 製品Xの生産量は $7,600 \div 2.0 = 3,800$ 袋へと大幅に減少する。
  • 失われる利益（機会原価）: $$(6,500 - 3,800) \times 1,220 = 2,700 \times 1,220 = \mathbf{3,294,000 \text{ 円}}$$
  • この $3,294,000$ 円の機会損失を、Y社向け $2,400$ 袋の価格引き上げによって全額回収しなければならない。
  • Y社1袋あたりの必要な値上げ幅： $$3,294,000 \text{ 円} \div 2,400 \text{ 袋} = \mathbf{1,372.5 \text{ 円}}$$
  • 新しい販売単価：現行の販売価格に値上げ幅を上乗せして逆算します。

第3問：取替投資の意思決定・NPV・期待値（配点30点） ⇒ 【コウジさんの獲得点：0点（未着手）】

1. 設問の全体像

  • 設問1（8点）: 新機械導入に伴う初年度（1年度）および2年度のキャッシュフロー増加額を算出。
  • 設問2（10点）: 複利現価係数・年金現価係数を用いて正味現在価値（NPV）を算出。
  • 設問3（12点）: 市場調査による将来予測情報（確率）を加味したNPV期待値を算出し、投資判断を行う。

2. 深掘り講義：取替投資のキャッシュフローを解剖する3大要素

取替投資（既存設備を捨てて新設備を導入する投資）のCF計算は、以下の「3つの要素」に分解して整理すれば決して怖くありません。

［取替投資の増分CF］＝ ① 営業利益の増分に対する税引後CF
                     ＋ ② 減価償却費の増分によるタックスシールド
                     ＋ ③ 旧設備売却に伴う売却損の節税効果（初年度のみ）
                     − ④ 運転資本の増分投資（回収時はプラス）
① 旧設備の売却損に伴う節税効果（タックスシールド）
  • 既存の機械を売却した際、帳簿価額（簿価）より低い価格でしか売れなかった場合、「固定資産売却損」が発生します。
  • 売却損が発生すると、その分だけ会社全体の課税所得が圧縮され、「売却損 × 法人税率」の分だけ納税額が減少（キャッシュが手元に残る）します。
  • これが取替投資特有のキャッシュイン効果です。
② 増分キャッシュフローの基本算式

$$\Delta \text{CF} = (\Delta \text{売上} - \Delta \text{現金支出費用}) \times (1 - t) + \Delta \text{減価償却費} \times t$$ （※ $t$ は実効税率）

  • 設問1の模範正解:
  • 初年度（1年度）CF増加額：69 万円
  • 2年度CF増加額：74 万円
  • 設問2の模範正解:
  • 正味現在価値（NPV）：51.14 万円（NPV ＞ 0）
  • 設問3の模範正解:
  • 正味現在価値の期待値：18.96 万円
  • 投資判断：実行すべきである（期待値が正であるため）

第3問は配点が30点と極めて大きいため、設問1（初年度・2年度のCF）だけでも拾えれば、それだけで8点を積み増すことができます。

第4問：管理会計・振替価格と業績評価（配点25点） ⇒ 【コウジさんの獲得点：8点】

（設問1）全部原価加算振替価格の問題点（80字以内、配点13点） ⇒ 【2点 / 13点】

  • コウジさんの解答（54字）:

    事業部間の販売に利潤を載せることによって加工事業部が外部顧客に販売する誘因が損なわれ売上減少につながる。

  • 採点評価:
  • 内部振替価格に利益を上乗せすることによるインセンティブの歪みに触れており部分点2点。
  • しかし、「全部原価加算方式」特有の問題点（固定費と操業度の関係）への言及が不足していました。
  • 管理会計の本質講義：全部原価加算の何が問題なのか？:
  • 全部原価の構成: 変動製造費用だけでなく、「固定製造間接費（固定費）」が含まれている。
  • 操業度による単価変動:
    • 生産量（操業度）が低下すると、固定費がより少数の製品に配賦されるため、製品1単位あたりの固定費負担額が跳ね上がり、全部原価が高騰する。
    • その結果、供給側事業部の効率改善努力とは無関係に、操業度の変動だけで振替価格が変動してしまう。
  • 業績評価の歪み:
    • 供給事業部の非効率や操業度リスクが、振替価格を通じて購入側事業部に押し付けられる。
    • どちらの事業部にとっても、自己の管理可能な努力が正当に評価されない事態が生じる。
  • 模範解答例（80字）:

    全部原価に含まれる固定費が生産量（操業度）により左右されるため、事業部の原価低減努力とは無関係に振替価格が変動し、事業部間の適正な業績評価が阻害される点。（78字）

（設問2）事業部長の業績評価における留意点（60字以内、配点12点） ⇒ 【6点 / 12点】

  • コウジさんの解答（77字）:

    事業部長がコントロールできない設備投資にかかる固定費を営業利益に足し戻した金額で評価することで評価の公平性を高めモチベーションを損なわぬよう留意する。

  • 採点評価:
  • 内容評価：9点 / 12点（ほぼ満点）
  • 文字数超過ペナルティ（60字指定に対し77字、17字超過）：-3点
  • 獲得点：6点
  • 講評と解説:
  • 「事業部長がコントロールできない設備投資にかかる固定費を除外する」という解答は、管理会計論の根本原則である「コントロール可能性の原則（管理可能利益の原則）」を完璧に見抜いています。
  • 社長が設備投資の決定権を握っている以上、それに伴う減価償却費は事業部長にとって管理不能コストです。管理不能なコストで部下を評価すると、不当な不公平感を生みモチベーションを破壊します。
  • あとは文字数を削る技術だけです。
    • 60字推敲例: 「設備投資に伴う減価償却費等の管理不能費を除外し、事業部長が管理可能な貢献利益や管理可能利益で評価する点。（53字）」

第2部：事例Ⅳで一生使える「財務・管理会計の5大論点」

論点1：経営分析の高速絞り込みルーティン

  1. 目視でアタリをつける: 財務諸表全体から乖離の大きい科目を3つ特定する。
  2. 計算は5指標以内: 収益性（営業利益率）、効率性（有形固定資産回転率）、安全性（自己資本比率または負債比率）を固定する。
  3. 記述は3ブロックテンプレート: 「強み指標＋要因」で効率性に優れるが、「弱み指標1＋要因」で安全性が低く、「弱み指標2＋要因」で収益性に課題がある。
  4. 20分強制リミッター: 20分が経過したら途中でも次の大問へ移る。

論点2：制約条件下の意思決定（セールスミックス）

  1. 制約条件（ボトルネック）が1つの場合、「ボトルネック資源1単位あたりの限界利益」を比較する。
  2. 時間あたり限界利益の大きい製品を、需要上限まで最優先で生産する。
  3. 残余資源をもう一方の製品に割り当てる。
  4. 機会原価が発生する場合、失われる限界利益を新規受注の数量で割って必要単価を逆算する。

論点3：取替投資の意思決定（NPV・タックスシールド）

  1. 初年度期首：新機械の取得支出（キャッシュアウト） − 旧機械の売却収入 ＋ 旧機械売却損に伴う節税額（タックスシールド）。
  2. 各年度の営業CF：$(\Delta \text{売上} - \Delta \text{現金支出費用}) \times (1 - t) + \Delta \text{減価償却費} \times t$。
  3. 運転資本：増加時は支出（マイナス）、プロジェクト終了時の回収は収入（プラス）。
  4. 複利現価係数・年金現価係数を用いて現在価値に割り引き、NPVを算出。

論点4：組織の管理会計（振替価格・管理可能利益）

  1. 全部原価加算方式の問題点: 固定費が含まれるため、操業度の変動によって製品単価が左右され、努力と業績が乖離する。
  2. 改善策: 変動原価加算方式、または外部市場価格を基準とする市価基準振替価格の採用。
  3. コントロール可能性の原則: 事業部長が決定権限を持たないコスト（設備投資の減価償却費や本社費配賦額）を業績評価から除外し、管理可能利益（または貢献利益）で評価する。

論点5：80分のタイムマネジメントと解く順序の絶対法則

  • 第1問（経営分析）: 00〜20分（目標20〜25点）
  • 第4問（記述問題）: 20〜35分（目標15〜18点）※計算ミスのない記述を先に確保！
  • 第2問（CVP・セールスミックス）: 35〜55分（目標12〜16点）
  • 第3問（意思決定・NPV）: 55〜80分（目標10〜15点、設問1の部分点を確実に拾う）
