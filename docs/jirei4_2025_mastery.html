第2問：CVP分析・セールスミックス（配点30点） ⇒ 【コウジさんの獲得点：17点】

設問1：損益分岐点分析（10点満点） $\implies$ 【10点満点！】

  • 条件: 製品Xと製品Yの販売数量比率が $2 : 3$。
  • コウジさんの完璧な立式:
  • 1基あたり限界利益：$X = 600 - 230 = 370$ 千円、$Y = 560 - 140 = 420$ 千円。
  • 販売数量比率：$y = \frac{3}{2}x$。
  • 固定費合計：個別固定費 $45,000 + 35,000$ ＋ 共通固定費 $400,000 = 480,000$ 千円。
  • 連立方程式：$370x + 420 \times \frac{3}{2}x = 480,000 \implies 1,000x = 480,000 \implies x = 480$ 基、$y = 720$ 基。
  • 損益分岐点売上高：$600 \times 480 + 560 \times 720 = \mathbf{691,200}$ 千円。
  • 完璧な計算で満点です。

設問2：目標利益達成のための販売数量（10点満点） $\implies$ 【7点】

  • 条件: 変動費が5%上昇、共通固定費が10%上昇、製品Xの販売数量が500基のとき、目標営業利益50,000千円を達成する製品Yの必要数量。
  • コウジさんの立式:
  • 変動費上昇後：
    • $X$限界利益 $= 600 - 230 \times 1.05 = 358.5$ 千円
    • $Y$限界利益 $= 560 - 140 \times 1.05 = 413.0$ 千円
  • 共通固定費上昇後：$400,000 \times 1.1 = 440,000$ 千円
  • 目標方程式： $$358.5 \times 500 + 413y = 50,000 + (45,000 + 35,000 + 440,000)$$ $$179,250 + 413y = 570,000 \implies 413y = 390,750 \implies y = 946.1259...$$
なぜ「946基」ではなく「切り上げ947基」なのか？（利益差異シミュレーション）

四捨五入して946基とした場合と、切り上げて947基とした場合の営業利益を検証します。

$$\begin{aligned} \text{946基の場合の利益} &= 179,250 + 413 \times 946 - 520,000 = 179,250 + 390,698 - 520,000 = \mathbf{49,948 \text{ 千円}} \ (< 50,000 \text{千円}) \ \text{947基の場合の利益} &= 179,250 + 413 \times 947 - 520,000 = 179,250 + 391,111 - 520,000 = \mathbf{50,361 \text{ 千円}} \ (\ge 50,000 \text{千円}) \end{aligned}$$

946基では目標利益50,000千円に対して52千円不足（未達）してしまいます。 経営計画上、「目標利益を達成する」という命題を満たすためには、1基多く生産・販売しなければならないため、端数は必ず「切り上げ（947基）」となります。

設問3：制約条件付き利益最大化（10点満点） $\implies$ 【0点（見送り・英断）】

  • コウジさんはこの設問を「計算が複雑そう」と判断して即座にスキップしました。
  • 解法の完全解説:
  • 直接作業時間の上限制約：製品Xは1基あたり4時間、製品Yは1基あたり2時間を要し、総作業時間の上限は5,000時間。
  • 時間あたり限界利益の比較：
    • 製品X：$358.5 \div 4 = 89.625$ 千円 / 時間
    • 製品Y：$413.0 \div 2 = 206.500$ 千円 / 時間
  • 製品Yの時間あたり限界利益が製品Xの2倍以上高いため、製品Yを販売可能上限（1,500基）まで最優先で生産。
  • 製品Y消費時間：$1,500 \times 2 = 3,000$ 時間。
  • 残余時間：$5,000 - 3,000 = 2,000$ 時間。
  • 製品X生産可能量：$2,000 \div 4 = 500$ 基。
  • 最大営業利益：$358.5 \times 500 + 413.0 \times 1,500 - 520,000 = 179,250 + 619,500 - 520,000 = \mathbf{278,750}$ 千円（総利益：$408,750$ 千円）。
  • 実戦において、この計算に10分以上拘泥して第3問の時間を失うリスクを回避したコウジさんの判断は、戦略的に大正解でした。

2. 機会費用（他社貸出賃料 2,400千円）の本質

  • なぜ賃料収入を費用として差し引くのか？
  • 工場として自社利用する倉庫は、「もしこの投資案を採用しなければ、他社に年間2,400千円で貸し出して確実に得られていた収入」です。
  • 新規投資を実行することによって「得られるはずだった収入を諦める（逸失利益）」ことになるため、これは明らかな投資案の増分コスト（機会費用）です。

3. 減価償却のタックスシールド算定アプローチ

税引後営業キャッシュフローの計算には2つのアプローチがありますが、結果は完全に一致します。

$$\begin{aligned} \text{アプローチA（利益＋償却費）} &: (90,000 - 36,000 - 30,000 - 2,400 - 15,000) \times 0.7 + 15,000 = 6,600 \times 0.7 + 15,000 = 4,620 + 15,000 = \mathbf{19,620} \ \text{アプローチB（現金収支＋TS）} &: (90,000 - 36,000 - 30,000 - 2,400) \times 0.7 + 15,000 \times 0.3 = 21,600 \times 0.7 + 4,500 = 15,120 + 4,500 = \mathbf{19,620} \end{aligned}$$

コウジさんはアプローチBを用いており、計算プロセスの美しさは群を抜いています。

第2部：事例Ⅳで一生使える「財務・投資意思決定の5大セオリー」

セオリー1：経営分析の高速絞り込み（目視アタリ付け）

  1. P/L目視: 売上高に対する原価と販管費の重さを確認（総利益率か営業利益率かを即決）。
  2. B/S目視: 有形固定資産と純資産の厚さを確認（有形固定資産回転率と自己資本比率を即決）。
  3. 電卓作業は3指標限定: 5分以内に計算完了。
  4. 80字記述テンプレート: 「強み指標＋戦略要因」「弱み指標1＋戦略要因」「弱み指標2＋戦略要因」を接続詞で結合。

セオリー2：目標利益・損益分岐点における端数処理（切り上げの原則）

  • 目標利益を達成するための必要数量・売上高は、端数が生じた時点で必ず「切り上げ」。
  • 1基でも不足すると目標利益未達になるため、経営判断として切り上げが絶対の正解。

セオリー3：制約条件下の意思決定（ボトルネック資源あたり限界利益）

  • 制約資源（作業時間・機械時間）が1つの場合、「制約資源1単位あたりの限界利益」を比較。
  • 時間あたり利益が高い製品を需要上限まで最優先で生産し、残余時間を他製品に配分。

セオリー4：設備投資意思決定の3階建てタイムライン

  • 最終年度（n年目）のキャッシュフローは必ず以下の3階建てで整理する：
  • 通常の税引後営業CF
  • 運転資本の全額回収（プラス）
  • 残存設備の税引後売却処分額（簿価との差額に課税考慮）

セオリー5：コーポレートファイナンスの資金調達原則（期間対応とWACC）

  • 長期設備投資には長期資金を充当（期間対応の原則）。
