事例Ⅱの深層マーケティング理論：ブランド価値構造（感覚価値・観念価値）と周辺論点の完全攻略

🎧 AUDIO OVERVIEW この資料の対話型ポッドキャスト解説

はじめに：なぜ今、事例Ⅱで「学術マーケティング理論」が狙われるのか？

近年の第2次試験・事例Ⅱにおいて、令和5年度の「ダイナミック・プライシング」、令和6年度の「ブランド価値構造（感覚価値・観念価値）」のように、1次試験の企業経営理論や現代マーケティングの学術用語が直接設問に指定されるケースが急増しています。

多くの受験生は「そんな専門用語は知らない！」とパニックになりがちですが、試験委員のメッセージは明確です。 「中小企業が、大手資本の価格破壊（100円均一・安価な輸入品・大手EC）に勝つためには、小手先の安売りではなく、強固なブランド理論と顧客体験（CX）に基づいた高付加価値化戦略をとらなければならない」 という強い意志があるからです。

本書では、令和6年度で問われた「感覚価値・観念価値」の根本理論を解剖するとともに、事例Ⅱで連動して出題される「体験価値（コト消費・イミ消費）」「サブスク・サーキュラーエコノミー」「オムニチャネル・OMO」「地域創生・関係人口」などの周辺論点を網羅的に体系化します。

第1章：ブランド価値構造の完全体系

1. 「4つの価値ピラミッド」とは何か？

学術マーケティング（恩蔵直人教授等のブランド価値構造論）において、顧客が製品やサービスから受け取る価値は、以下の4階層のピラミッドとして整理されます。

　　　　　　　▲
　　　　　　 / 観 \　　【観念価値】（意味・物語・誇り・理念・自己表現）
　　　　　　/  念  \　　★中小企業の主戦場！真似できない競争優位
　　　　　 /───\
　　　　　/  感  覚  \　【感覚価値】（五感の美しさ・美味しさ・手触り・映え）
　　　　 /─────\　★顧客の感情を揺さぶり、購買の引き金になる
　　　　/   便   宜   \ 【便宜価値】（買いやすさ・安さ・納期の早さ・手軽さ）
　　　 /───────\ ※大企業や大手ECの独壇場（中小は勝負を避ける）
　　　/    基    本    \【基本価値】（製品本来の基本機能・仕様・安全性）
　　 /─────────────────\ ※満たして当たり前（コモディティ化）
階層 価値の種類 定義と本質 具体例（陶磁器・食器の場合） 2次試験での戦略的意味
下層 基本価値
(機能価値)		 道具や製品としての物理的・本来的な機能・性能。 料理を載せられる、割れにくい、電子レンジ対応。 満たしていて当然。差別化の源泉にはならない。
中下層 便宜価値
(利便価値)		 入手のしやすさ、価格の安さ、手軽さ、アクセスの良さ。 100円均一で買える、翌日Amazonで届く。 中小企業が最も戦ってはいけない領域（規模の経済で負ける）。
中上層 感覚価値
(感性価値)		 五感（視覚・触覚・味覚・聴覚・嗅覚）を通じて直感的に心地よい、美しい、快いと感じる魅力。 料理が美しく見える盛り付け映え、写真映え、手作業の土の温もり、直火で調理したときの音や香り。 中小企業の強力な差別化武器！
SNS時代において爆発的な拡散と初回購入の動機になる。
最上層 観念価値
(意味価値)		 製品の背景にある物語、職人の想い、地域の伝統・歴史、理念への共感、誇り、自己表現。 零細な職人の手仕事への敬意、3代目の情熱、伝統産業を応援する誇り、「丁寧な暮らし」を送る自分のアイデンティティ。 ブランドの究極の到達点！
他社が絶対に模倣できない「愛顧（ロイヤルティ）」と「価格プレミアム」を生む。

2. なぜ中小企業は「感覚価値」と「観念価値」で戦わねばならないのか？

  • コモディティ化の罠からの脱出: 現代はモノがあふれ、基本価値（お皿としての機能）や便宜価値（安さと早さ）は大企業や100円ショップ、安価な輸入品が圧倒的に有利です。中小企業がここで戦うと、待っているのは過酷な消耗戦（赤字・下請けいじめ）だけです。
  • 高価格を受け入れてもらう唯一の論理: 消費者が1枚3,000円〜5,000円の作家物の陶磁器を買う理由は、「お皿が足りないから」ではありません。 「料理が格段に美味しそうに見える（感覚価値）」からであり、「その器を作った職人の物語に共感し、使うたびに心が豊かになる（観念価値）」からです。
  • 2次試験答案での表現パターン:
  • 感覚価値を訴求するフレーズ：
    • 「視覚的な盛り付け映えや写真映えを訴求し」
    • 「直火調理の実演や五感に訴える体験を提供し」
    • 「職人の手仕事による独特の手触りや質感を体感させ」
  • 観念価値を訴求するフレーズ：
    • 「伝統的工芸品を受け継ぐ職人の情熱や産地の物語を伝え」
    • 「地域文化への共感や作り手を応援する誇りを醸成し」
    • 「持続可能な地場産業を支える意義に共感させ」

第2章：周辺論点① 体験価値マーケティング（CX）と「コト消費・イミ消費・エモ消費」

1. バーンド・H・シュミットの「5つの体験モジュール（SEMs）」

マーケティング学者シュミットは、顧客体験（Customer Experience: CX）を以下の5つに分類しました。事例Ⅱのイベント企画や店舗施策のアイデア出しに直結します。

  1. Sense（感覚的体験）：五感への刺激（洗練された店舗内装、心地よいBGM、カフェの香り）。
  2. Feel（情緒的体験）：親しみ、安心感、感動（温かい接客、職人の笑顔、おもてなし）。
  3. Think（知的・思考的体験）：知的好奇心の刺激（器の歴史を知る、盛り付けのコツを学ぶワークショップ）。
  4. Act（行動的・身体的体験）：ライフスタイルの変化（直火陶磁器で自分で料理を作ってみる、陶芸体験）。
  5. Relate（関係的体験）：コミュニティや他者との繋がり（職人と語り合う、愛好家同士で盛り付け写真をシェアする）。

2. 「モノ消費」から「コト消費」、そして「イミ消費」「エモ消費」へ

  • コト消費（体験価値）： モノを買うこと自体ではなく、それを使った「体験」「時間」「思い出」にお金を払う（例：カフェスペースでの軽食体験、3代目の盛り付け教室）。
  • イミ消費（社会・地域貢献）： その消費が社会や地域、環境にとってどのような「意味」を持つかを重視して購入する（例：ふるさと納税で衰退する地場産業を応援する、伝統工芸の後継者を育てる）。
  • エモ消費（共感・精神的充足）： 感情が動かされること（エモーショナル）にお金を使う（例：3代目のひたむきな挑戦を応援したい、動画を見て感動した）。

第3章：周辺論点② 「所有から利用へ」のビジネスモデル進化

1. なぜ工芸品・高価格品で「サブスク・レンタル」が最強の武器になるのか？

事例Ⅱで頻出する「買いたいけれど買えない顧客の心理的摩擦（フリクション）」を打ち破るのが、サブスクリプションやレンタルです。

顧客の心理的ハードル（ペイン） 従来のモノ売り（販売） 新しいビジネスモデル（サブスク／レンタル）
「高価で失敗したくない」 買うのを諦める 「月額定額で試せる（利用ハードルの低減）」
「収納場所がない・置けない」 買わずに我慢する 「使わなくなったら返却・交換できる」
「今あるものが捨てられない」 新しい器を買えない 「不要な食器の下取り・引き取りサービスの併設」
「どれを選べばいいかわからない」 迷って離脱する 「3代目が季節や料理に合わせて厳選セレクト（キュレーション）」

2. 産地問屋の新しい存在意義：「キュレーター（編集者）」

  • かつての問屋は「ただ物を右から左へ流す物流・中間マージン業者」でした。
  • しかし直販（D2C）が普及した現代、問屋が生き残る道は「キュレーション（目利き・編集・プロデュース）」です。
  • 個々の窯元は零細で自力発信ができません。そこに問屋が入り、「複数の窯元の魅力を束ね、テーマ（季節、料理、ライフスタイル）を設定して届ける」ことで、産地全体のプラットフォームとして莫大な付加価値を生み出します。

第4章：周辺論点③ チャネル戦略の進化（オムニチャネルからOMOへ）

1. チャネル進化の4段階

  1. シングルチャネル：実店舗のみ、または卸売のみ。
  2. マルチチャネル：実店舗とECを別々に運営（在庫や顧客情報がバラバラ、社内競合が発生）。
  3. クロスチャネル：店舗在庫をECで確認できるなど、部分的にシステムが連携。
  4. オムニチャネル（Omni-Channel）：店舗、EC、SNS、アプリなどあらゆるチャネルが統合され、顧客がどこからでもシームレスに同じ体験・購入ができる状態。
  5. OMO（Online Merges with Offline）：オンラインとオフラインが完全に融合。実店舗が「モノを買う場所」から「ブランドを五感で体験し、対話するショールーム」へと再定義される。

2. 事例Ⅱにおける「オムニチャネル成功の黄金循環」

第4問のような設問では、以下の循環ストーリーを描くことで満点が狙えます。

【ステップ1：集客・送客（O2O）】
　SNS・動画・ECで認知獲得 ⇒ 店舗限定特典・カフェクーポンでリアル店舗へ誘客
　　↓
【ステップ2：五感体験・関係性構築（オフラインの強み）】
　スタイリッシュな店舗・カフェで五感体験 ⇒ 盛り付け講座・職人との対話で「ファン化」
　　↓
【ステップ3：顧客データ統合・LTV最大化（オンラインの強み）】
　店舗での接客情報・購入履歴を一元管理 ⇒ 帰宅後もECで季節ごとの新作を定期案内・リピート

第5章：周辺論点④ 地域ブランディングと「関係人口」マーケティング

1. ふるさと納税を「通販のディスカウント」にしない戦略

  • ふるさと納税を単なる「肉や米の量・還元率の勝負」にすると、中小都市や工芸品は大手産地に敗北します。
  • 解決策：ストーリーと体験の抱き合わせ（コト・イミ消費化）:
  • 食器単体ではなく、「地域の郷土料理の食材・発酵調味料 ＋ 直火対応食器 ＋ 料理長直伝レシピ動画」をセットにする。
  • 返礼品を受け取った寄付者が、自宅にいながらX市の食文化と伝統工芸を体験できるようにする。

2. 寄付者を「関係人口」から「熱狂的ファン」へ育てるナーチャリング

  • 関係人口とは: 移住した「定住人口」でもなく、1回観光に来ただけの「交流人口」でもない、「地域と多様に関わり続ける人々（ファン、応援団、リピーター）」のこと。
  • ナーチャリング（顧客育成）の手法:
  • 返礼品に職人の手書きメッセージや3代目の動画URLを同封。
  • 「陶磁器祭り」の優先招待状や、自社カフェの特別優待券を送付。
  • ふるさと納税をきっかけに、実際にX市を訪れて店舗や窯元を巡る「聖地巡礼」へと繋げる。

第6章：試験本番で「未知の学術用語」が出たときの超実戦的解法マニュアル

もし本番で、見たことも聞いたこともない専門用語（例：サービス・ドミナント・ロジック、ナラティブ・アプローチ、マスカスタマイゼーション等）が出題されたら、次の3ステップで冷静に解体してください。

ステップ1：漢字・英単語を「日常語」にほぐす

  • 例：「感覚価値」⇒ 感覚＝五感（目・耳・鼻・舌・肌）。五感で感じる魅力！
  • 例：「観念価値」⇒ 観念＝頭の中の考え、理念、心。背景の物語や理念への共感！
  • 例：「ダイナミック・プライシング」⇒ ダイナミック＝動的・変動。需要に合わせて価格を変えること！

ステップ2：与件文の中にある「対応する事実」を探す

  • 設問に専門用語があるということは、「与件文の中に、その用語に対応する具体的なエピソードが必ず書かれている」という試験委員からのヒントです。
  • 「五感で感じるもの」はどこだ？ ⇒ 「料理が映える盛り付け」「直火で簡単にできる郷土料理」。
  • 「背景の物語や想い」はどこだ？ ⇒ 「窯元職人の真剣な姿」「地場産業の伝統」。

ステップ3：設問のキーワードをそのまま解答文の「主語・述語」に使う

  • 採点官は、指定したキーワードが正しく使われているかを機械的にチェックします。
  • 「〜により『感覚価値』に訴求し、〜によって『観念価値』への共感を醸成する」 というように、指定語句を堂々と文中に組み込んで因果関係を完成させます。

まとめ：事例Ⅱを制する「価値創造」のマインドセット

事例Ⅱの本質は、常に「顧客の心（インサイト）に寄り添い、自社にしかない強み（コア・コンピタンス）を、最適な形（製品・価格・チャネル・プロモーション）に翻訳して届けること」にあります。

基本価値や便宜価値の安売り合戦から抜け出し、感覚価値（五感の感動）と観念価値（理念・物語への共感）を届けること。これこそが、中小企業が荒波を生き残り、顧客から生涯愛される企業へと飛翔するための唯一無二の王道戦略です。
