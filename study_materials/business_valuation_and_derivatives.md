# 📘 事例Ⅳ 企業価値評価（DCF/配当割引）・M&A・為替デリバティブヘッジ完全攻略
〜フリーキャッシュフロー・WACC・継続価値から為替予約・通貨オプションまで〜

## はじめに：なぜ企業価値評価と為替ヘッジが事例Ⅳで問われるのか？

中小企業診断士2次試験の事例Ⅳでは、経営分析やCVP、設備投資NPVといった王道論点に加え、数年に一度の頻度で**「企業価値評価（M&A・事業承継）」**や**「為替リスク管理（デリバティブ）」**が出題されます。

これらの論点は、多くの受験生が「難解なファイナンス理論」として敬遠し、対策が手薄になりがちです。しかし、出題されるパターンと計算構造は驚くほど定型化されており、仕組みさえ理解していれば**確実に満点や部分点を奪取できるボーナス問題**へと変わります。

本ガイドでは、以下の核心論点を体系的・論理的に解剖します。

1. **インカム・アプローチ（DCF法・配当割引モデル）の完全構造**
2. **継続価値（ターミナルバリュー）とゴードン成長モデルの計算**
3. **M&Aにおけるシナジー、のれん（Goodwill）、買収プレミアム**
4. **マーケット・アプローチ（マルチプル法）とコスト・アプローチ（時価純資産法）**
5. **外貨建て取引における為替リスクと2大デリバティブ（為替予約 vs 通貨オプション）**

## 第1章：企業価値評価（Valuation）の全体体系

企業価値評価の手法は、評価の基礎とする情報源によって大きく3つのアプローチに分類されます。

```
［企業価値評価の3大アプローチ］
  ├─ ① インカム・アプローチ（将来の収益力に着目）
  │    ├─ DCF法（割引キャッシュフロー法）：最も本質的・標準的
  │    └─ 配当割引モデル（DDM）：株主への配当金を割り引く
  │
  ├─ ② マーケット・アプローチ（市場の取引価格・他社比較に着目）
  │    ├─ 類似会社比較法（マルチプル法：EV/EBITDA倍率、PER倍率、PBR倍率）
  │    └─ 類似取引比較法
  │
  └─ ③ コスト・アプローチ（企業の保有資産に着目）
       ├─ 簿価純資産法
       └─ 時価純資産法（＋営業権・のれん）
```

中小企業の事業承継やM&A、試験問題においては、理論的厳密さを問う**「DCF法」「配当割引モデル」**と、中小企業の実務で多用される**「時価純資産法＋営業権」**の対比が頻出です。

## 第2章：DCF法（割引キャッシュフロー法）の計算アルゴリズム

DCF法は、企業が生み出す将来のフリーキャッシュフロー（FCF）を、資本コスト（WACC）で現在価値に割り引いて事業価値を算出する手法です。

### 1. 企業価値・事業価値・株式価値の関係性（B/Sの視点）

貸借対照表（時価ベース）をイメージすると、各概念の包含関係が論理的に整理されます。

```
【資産サイド（借方）】                     【負債・純資産サイド（貸方）】
┌─────────────────────────┐             ┌─────────────────────────┐
│                         │             │ 有利子負債（時価）       │
│ 事業価値（EV）           │             │ （借入金、社債等）      │
│ （将来FCFの現在価値合計）│             ├─────────────────────────┤
│                         │             │                         │
├─────────────────────────┤             │ 株式価値（株主価値）    │
│ 非事業用資産             │             │ （時価純資産・自己資本）│
│ （余剰現預金、遊休不動産│             │                         │
│   投資有価証券等）      │             │                         │
└─────────────────────────┘             └─────────────────────────┘
  └───────┬───────────────┘               └───────────┬───────────┘
      【企業価値】                                【企業価値】
```

#### 基本等式
1. **企業価値** ＝ **事業価値** ＋ **非事業用資産**
2. **株式価値（株主価値）** ＝ **企業価値** − **有利子負債**  
   または  
   **株式価値** ＝ **事業価値** − **ネット有利子負債**（※ネット有利子負債 ＝ 有利子負債 − 非事業用現預金）
3. **1株当たり株式価値** ＝ **株式価値** $\div$ **発行済株式数**

> **【注意】**  
> 問題文で「事業価値」を求められているのか、「企業価値」なのか、「株式価値（株主価値）」なのか、「1株当たり価値」なのかを必ず確認すること。ここを取り違えると最終行で失点します。

---

### 2. フリーキャッシュフロー（FCF）の算出式

企業価値評価におけるFCFは、**「債権者（銀行）と株主の両方に帰属するキャッシュフロー」**です（アンレバードFCF）。

```
［フリーキャッシュフロー（FCF）］
  ＝ 営業利益 × (1 − 法人税率)
     ＋ 減価償却費
     − 設備投資額（有形・無形固定資産の増加額）
     − 正味運転資本増加額（Δ売上債権 ＋ Δ棚卸資産 − Δ仕入債務）
```

- 支払利息は引いてはいけません（割引率であるWACCの中に負債コストとして織り込まれているため、二重控除を防ぐ）。
- 減価償却費は非現金支出費用なので足し戻します。
- 設備投資と運転資本の増加は現金の流出なので控除します。

---

### 3. 継続価値（ターミナルバリュー）の算定式

企業の寿命は永久に続くと仮定されるため、有限の予測期間（例：5年）以降のキャッシュフローを**「継続価値（Terminal Value, TV）」**として一括集計します。

#### ゴードン成長モデル（定率成長モデル）
予測期間最終年度（第$n$期）の翌期以降、FCFが年率 $g$（永久成長率）で永久に成長し続けると仮定した場合：

$$TV_n = \frac{FCF_{n+1}}{WACC - g} = \frac{FCF_n \times (1 + g)}{WACC - g}$$

- $WACC$：加重平均資本コスト
- $g$：永久成長率（問題文で指定される。ゼロの場合は $TV_n = \frac{FCF}{WACC}$）
- **現在価値への割引**：第$n$期末時点の価値であるため、これを**さらに初年度（現在）まで割り戻す**必要があります。

$$\text{継続価値の現在価値} = \frac{TV_n}{(1 + WACC)^n}$$

> **【計算の落とし穴】**  
> $TV_n$ を求めた後、$(1 + WACC)^n$ で割り引くのを忘れるミスが多発します。必ず「$n$期末時点の金額」であることを意識してください。

## 第3章：配当割引モデル（Dividend Discount Model, DDM）

配当割引モデルは、**「株式価値は、将来株主が受け取る配当金の現在価値の合計に等しい」**という理論です。株主資本コスト（$r_e$）を用いて割り引きます。

### 1. ゼロ成長モデル（永久年金型）
毎年同額の配当金 $D$ が永久に支払われる場合：

$$P = \frac{D}{r_e}$$

- $P$：現在の株価（株式価値）
- $D$：1株当たり配当金
- $r_e$：株主資本コスト（CAPM等で算定）

### 2. 定率成長配当割引モデル（ゴードンモデル）
配当金が毎期一定割合 $g$ で永久に成長し続ける場合：

$$P = \frac{D_1}{r_e - g} = \frac{D_0 \times (1 + g)}{r_e - g}$$

- $D_0$：当期の配当金
- $D_1$：翌期の予想配当金
- $r_e$：株主資本コスト（※必ず $r_e > g$）
- $g$：配当成長率

#### サステイナブル成長率（内部留保による成長率）
配当成長率 $g$ は、企業の再投資能力によって決まります。

$$g = ROE \times (1 - \text{配当性向}) = ROE \times \text{内部留保率}$$

## 第4章：M&A・のれん（Goodwill）・買収プレミアム

### 1. のれん（Goodwill）の発生メカニズム
M&Aにおいて、買い手企業が支払った買収対価が、対象企業の**「時価純資産」**を上回る場合、その差額が**「のれん（資産）」**として計上されます。

```
［のれん］＝［買収対価］−［被買収企業の時価純資産（時価資産 − 時価負債）］
```

- のれんの本質は、対象企業が持つ**「将来の超過収益力（ブランド力、技術力、顧客基盤、組織力）」**です。
- **日本の会計基準**: 20年以内の定額法で規則的に減損・償却（営業費用または販管費として計上）。
- **IFRS（国際財務報告基準）**: 規則償却は行わず、毎期減損テストを実施。

### 2. 買収プレミアムとシナジー効果
買収企業が時価よりも高い価格（プレミアム）を支払う理由は、M&Aによって**「シナジー（相乗効果）」**が創出されると期待するためです。

1. **売上シナジー**：クロスセル、販売網の相互利用、ブランド力の活用による売上拡大。
2. **コストシナジー**：本社の間接部門統合、原材料の共同購買（規模の経済）、重複拠点の統廃合。
3. **財務シナジー**：信用力向上による借入金利の低下、節税効果。

## 第5章：為替リスク管理と金融デリバティブ

中小企業が海外取引（輸出・輸入）を行う際、避けて通れないのが**為替変動リスク（為替レートの変動によって損益がブレるリスク）**です。

### 1. 為替リスクの構造（輸出企業 vs 輸入企業）

| 区分 | 決済通貨 | 直面するリスク | 円高の影響 | 円安の影響 |
| :--- | :--- | :--- | :--- | :--- |
| **輸出企業** | 外貨建て（ドル受取） | **円高ドル安リスク** | **損失（為替差損）**<br>円換算の受取額が目減りする | **利益（為替差益）**<br>円換算の受取額が増加する |
| **輸入企業** | 外貨建て（ドル支払） | **円安ドル高リスク** | **利益（為替差益）**<br>円換算の支払額が減少する | **損失（為替差損）**<br>円換算の支払額が増加する |

---

### 2. 為替予約（Forward Exchange Contract）

将来の一定期日に、**あらかじめ取り決めた為替レート（予約レート）で外貨を売買することを銀行と約束する契約**です。

- **輸出企業**: 将来受け取る米ドルを売却して円を買う契約（**ドル売り・円買い為替予約**）。
- **輸入企業**: 将来支払う米ドルを購入して円を売る契約（**ドル買い・円売り為替予約**）。

#### 為替予約のメリット・デメリット
| 項目 | 特徴 |
| :--- | :--- |
| **メリット** | 将来の受取円額または支払円額が**1円単位まで完全に固定化**され、為替変動リスクがゼロになる。事前の事業計画・原価計算が狂わない。契約時の追加コスト（手数料相当はレートに含まれる）が原則不要。 |
| **デメリット** | **有利な方向へ為替が動いた場合の利益（為替差益）を完全に放棄**することになる。<br>（例：1ドル＝150円で輸出予約をした後、市場が160円の円安になっても、150円でしか換金できない）。一度契約すると原則キャンセル不可。 |

---

### 3. 通貨オプション（Currency Options）

将来の一定期日（または期間内）に、**あらかじめ取り決めた権利行使価格（Strike Price）で外貨を「買う権利（コール）」または「売る権利（プット）」を売買する取引**です。

- **コール・オプション（Call Option）**：外貨を**「買う権利」**。
  - **輸入企業**が活用：円安が進んだ場合は権利行使して上限レートでドルを調達。円高になった場合は権利を放棄して市場の有利なレートでドルを安く買う。
- **プット・オプション（Put Option）**：外貨を**「売る権利」**。
  - **輸出企業**が活用：円高が進んだ場合は権利行使して下限レートでドルを高値売却。円安になった場合は権利を放棄して市場の有利なレートでドルを高く売る。

#### 通貨オプションの損益構造（非対称性）
オプションの最大の特徴は、**「権利であって義務ではない」**という点です。

```
［通貨オプションの損益特性］
  不利な変動（損失側） → 権利を行使して損失を一定限度にブロック！
  有利な変動（利益側） → 権利を放棄して市場レートで無限に利益を享受！
```

#### 為替予約 vs 通貨オプションの比較マトリックス

| 比較項目 | 為替予約（先渡取引） | 通貨オプション（買う権利・売る権利） |
| :--- | :--- | :--- |
| **法的性質** | 契約上の**「義務」**（必ず予約レートで履行） | 権利者の**「権利」**（有利なら行使、不利なら放棄） |
| **下振れリスク** | 完全に排除（リスクゼロ） | 権利行使により一定水準でカット |
| **上振れ利益** | **享受できない**（完全に放棄） | **享受できる**（市場の有利なレートを獲得可能） |
| **コスト** | 初期費用は原則ゼロ（スプレッドのみ） | **オプション料（プレミアム）の支払いが必要**（掛け捨て） |
| **中小企業の適合性** | 資金繰りの確実性を最優先する場合に適する | コストを払ってでも為替差益を狙いたい場合に適する |

## 第6章：耳で解く！計算＆記述実践ドリル

### ドリル1：DCF法による株式価値の算定
- **条件**:
  - 予測期間（向こう3年間）のFCF：毎期100百万円
  - 4期目以降のFCF：100百万円で永久に一定（成長率 $g = 0$）
  - WACC：10%
  - 有利子負債：300百万円、余剰現預金（非事業用資産）：100百万円
- **解答プロセス**:
  1. 予測期間（1〜3期）FCFの現在価値合計:
     $$\frac{100}{1.1} + \frac{100}{1.1^2} + \frac{100}{1.1^3} = 90.91 + 82.64 + 75.13 = 248.68 \text{ 百万円}$$
  2. 継続価値（3期末時点）:
     $$TV_3 = \frac{100}{0.10} = 1,000 \text{ 百万円}$$
  3. 継続価値の現在価値:
     $$\frac{1,000}{1.1^3} = \frac{1,000}{1.331} = 751.31 \text{ 百万円}$$
  4. 事業価値（EV）:
     $$248.68 + 751.31 = 1,000 \text{ 百万円}$$
  5. 企業価値 ＝ 事業価値 $1,000$ ＋ 余剰現預金 $100 = 1,100 \text{ 百万円}$
  6. **株式価値** ＝ 企業価値 $1,100$ − 有利子負債 $300 = \mathbf{800 \text{ 百万円}}$

## まとめ：事例Ⅳファイナンス攻略の3大原則

1. **「企業価値」「事業価値」「株式価値」の境界線を厳密に区別する。**
2. **継続価値（ターミナルバリュー）は、$n$期末の金額を現在価値に割り戻す二段階計算を忘れない。**
3. **為替デリバティブは「為替予約＝義務（リスクゼロだがアップサイド喪失）」「オプション＝権利（アップサイド維持だがプレミアム負担）」の対比で即答する。**
