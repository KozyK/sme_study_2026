# 事例Ⅲ：生産方式混在・在庫発注管理・工場レイアウトの完全攻略ガイド

事例Ⅲ（生産・技術）において、QCDの現場改善から一歩踏み込んだ難問として出題されるのが、**「生産方式の混在トラブル」「在庫・発注方式の不備」「工場移転・レイアウト設計」**です。
本ドキュメントは、「標準品と特注品で現場が大混乱」「置き場が狭くて在庫が山積み」という構造的課題をスマートに解決するためのマスターデータです。

---

## 1. 「見込み生産」と「受注生産」の混在トラブルと解決策

中小製造業が生き残りをかけて「高付加価値な特注品（受注生産）」に乗り出す際、**「従来の標準品（見込み生産）と同じラインで作ろうとして現場が大混乱する」** のが典型パターンです。

```text
【混在による現場崩壊の構図】
  標準品（大量・定常的） ──┐
                          ├──▶ [同じ機械・同じライン] ──▶ 段取り替え頻発・どちらも納期遅れ！
  特注品（少量・飛び込み）─┘
```

### 助言の3大打ち手
1.  **生産ラインの分離（専用ライン化）**:
    *   稼働率の高い標準品ラインと、多品種少量の特注品ラインを物理的・計画的に分離する。
2.  **部品の共通化・モジュール化（遅延差別化）**:
    *   特注品であっても、内部部品や中間品は標準品と共通設計にする。
    *   途中工程までは「見込み」で作り置きし、最終工程でのみ特注仕様に加工する（ポストポーンメント）。
3.  **生産計画の平準化と枠取り（スロット）管理**:
    *   標準品をベースロード（緩衝材）として一定ペースで生産し、特注品の飛び込み枠をあらかじめ計画内に確保しておく。

---

## 2. 在庫管理と適正発注方式（保管スペースの圧迫解消）

「工場が狭いのに、原材料のまとめ買いで通路までモノが溢れている」「探すムダや欠品が頻発している」という課題への処方箋です。

### 助言の3大打ち手
1.  **ABC分析による重点管理**:
    *   **Aランク品（高額・重要部品）**: 「定期発注方式」を採用し、需要予測に基づき綿密に在庫コントロール。
    *   **B・Cランク品（汎用ボルト等）**: 「定量発注点方式」やツービン法（2箱法）を採用し、発注業務を簡素化。
2.  **発注ロットの小口化と分納化**:
    *   まとめ買いによる購入単価の安さよりも、在庫保管コスト・スペース圧迫・陳腐化リスクを優先し、小ロット・高頻度納入へ切り替える。
3.  **サプライヤーとの情報共有（VMIなど）**:
    *   仕入先（サプライヤー）に自社の生産計画・内示情報を早期開示し、必要最小限のジャストインタイム納入を促す。

## 3. 工場移転・新設とレイアウト改善（運搬ロスの排除）

長年の増築・増設で工場内が迷路化し、「工程間の移動距離が長すぎる」「モノの運搬で一日が終わる」という工場への助言です。

### 助言の3大打ち手
1.  **直線的一方向の動線（U字ライン等）**:
    *   「原材料受入 ➡ 加工 ➡ 組み立て ➡ 検査 ➡ 出荷」の流れが一方向にスムーズに流れるレイアウト（逆流・交差の排除）。
2.  **工程間の近接化（SLP手法の活用）**:
    *   前工程と後工程を隣接させ、中間仕掛品の運搬距離と保管スペースを最小化する。
3.  **人とモノの動線分離**:
    *   作業者の歩行動線と、フォークリフト・運搬台車の搬送動線を分離し、安全性の確保と運搬の停滞を解消する。

## 4. 解答でそのまま使える「記述モジュール（定番フレーズ集）」

| 狙い・論点 | 答案で使える定石フレーズ |
| :--- | :--- |
| **生産ライン分離** | 「標準品と特注品の生産ラインを分離し、段取り替えの頻度を削減して生産効率と納期遵守率の向上を図る。」 |
| **部品共通化** | 「部品の標準化・モジュール化を進め、中間品まで作り置く遅延差別化により、特注品の製造リードタイムを短縮する。」 |
| **発注方式見直し** | 「ABC分析により重要部品は定期発注、汎用品は発注点方式へ見直し、小ロット高頻度納入で在庫保管スペースを圧縮する。」 |
| **レイアウト改善** | 「原材料受入から出荷まで逆流や交差のない直線的一方向レイアウトへ再配置し、運搬ロスと仕掛品滞留を削減する。」 |
| **動線分離** | 「作業者動線と運搬動線を分離し、安全性の向上とフォークリフト等の運搬効率化により、工程間リードタイムを短縮する。」 |
