# 経営分析 最高効率ルーチン

事例Ⅳ第1問（経営分析）を最速で通過するための型。上から順に読めば、そのまま本番の作業手順になります。

---

## 1. 与件文フラグの確認（指標の当たりをつける）

与件文を読みながら、以下のマトリックスに該当するキーワード（フラグ）を探します。
見つかったフラグに対応する指標が、解答の候補です。

| 区分 | 採用する指標 | 【優】のフラグ | 【劣】のフラグ |
| :--- | :--- | :--- | :--- |
| 収益性 | **売上高総利益率** | 高付加価値、固定客、ブランド力、地元密着 | 価格競争、外注費高騰、原材料費の高騰 |
| 収益性 | **売上高営業利益率** | *(優で使うケースは稀)* | 人件費の高止まり、広告宣伝費、非効率な営業 |
| 収益性 | **売上高経常利益率** | *(優で使うケースは稀)* | 過大な借入金、重い支払利息 |
| 効率性 | **売上債権回転率** | 現金商売、回収サイトが短い | 売掛金の回収遅れ、与信管理の甘さ |
| 効率性 | **棚卸資産回転率** | 在庫管理の徹底、IT化、事業間シナジー | 不良在庫の滞留、見込み生産、品揃え過多 |
| 効率性 | **有形固定資産回転率** | 既存設備の有効活用、居抜き出店 | 過大な設備投資、稼働率低下、遊休資産 |
| 安全性 | **当座比率** | 手元資金が潤沢、資金繰り安定 | 短期借入金への依存、現金不足 |
| 安全性 | **自己資本比率** | 無借金経営、内部留保が厚い | 借入金過多、財務基盤の脆弱化 |
| 安全性 | **固定長期適合率**<br>*(フラグ成立時のみ)* | *(優で使うケースは稀)* | 短期借入で無理な設備投資（即倒産の危機） |

**注意**: 営業利益率と経常利益率が両方フラグを立てることは稀です。与件文の記述がどちらに該当するかで一方を選びます。

---

## 2. 問題用紙への書き込み（情報量の圧縮）

1. B/S・P/Lの数値の**下3桁を鉛筆で斜線で消す**。上3桁（百万円単位）だけで暗算する状態を作ります。
2. B/Sの流動資産の横に「**当座資産**（現預金＋売上債権＋有価証券）」の合計（上3桁）を手書きでメモします。

---

## 3. ヨコ倍率チェック（割り算をせずに優劣を判定）

指標ごとに「D社 ÷ 他社」の割り算をして％を出す代わりに、**分母となる項目の倍率を1つ出し、分子の倍率と大小比較するだけ**で◯×を判定します。

| ベース | 基準倍率の出し方 | 判定ルール |
| :--- | :--- | :--- |
| **売上高** | P/L「売上高」の倍率を出す（例：1.2倍） | 各利益の倍率が基準より**大きければ◯**<br>各資産の倍率が基準より**小さければ◯** |
| **流動負債** | B/S「流動負債」の倍率を出す（例：0.8倍） | 当座資産の倍率が基準より**大きければ◯** |
| **総資産** | B/S「総資産」の倍率を出す（例：1.1倍） | 自己資本の倍率が基準より**大きければ◯** |
| **自己資本＋固定負債** | 上3桁で合算し倍率を出す *(フラグ成立時のみ)* | 固定資産の倍率が基準より**小さければ◯** |

---

## 4. 最終決定と精緻な計算

1. ◯×の結果と、Step 1で拾った与件文フラグを突き合わせ、**最もリンクが強い3つの指標**（優1〜2・劣1〜2など、設問の指示に従う）を決定します。
2. **選ばれた3つについてのみ**、ここで初めて電卓を使い、指定の形式（小数点第3位を四捨五入等）で正確な数値を算出し、解答用紙に記入します。

---

## 5. 記述問題の書き方（設問2の型）

設問2は「特徴と課題を○字以内で述べよ」という記述問題です。以下のテンプレートに当てはめるだけで、安定して高得点が取れます。

### 記述テンプレート（80字の場合）

```
【原因】により【優の指標名が示す強み】である一方、【原因】により【劣の指標名が示す弱み】が課題である。
```

### 書き方のルール

| ルール | 内容 |
| :--- | :--- |
| **与件文のキーワードをコピペする** | 高度な推論や独自解釈は不要。Step 1で拾ったフラグ（与件文の言葉そのまま）を「原因」の部分に埋め込む。 |
| **指標名は出さず、意味を書く** | 「売上高総利益率が高い」ではなく「収益性が高い」「粗利率が高い」のように、指標が示す経営上の意味に変換する。 |
| **優と劣を対比構造にする** | 「〜である一方、〜が課題である」のように、強みと弱みを1文の中で対比させる。 |
| **字数は上限の9割以上を使う** | 80字なら72字以上。余白が大きいと情報不足で減点される。 |

### 実例（令和3年 事例Ⅳ 第1問 設問2）

> 地元密着の品揃えや固定客確保による高粗利と高在庫効率が特徴。一方で、人件費等の販管費負担による低収益性と、借入金依存による安全性の低さが課題である。（75字）

| 要素 | テンプレートの対応 |
| :--- | :--- |
| 「地元密着の品揃えや固定客確保」 | 与件文フラグのコピペ（原因） |
| 「高粗利と高在庫効率」 | 優の指標が示す強み（総利益率＋棚卸資産回転率） |
| 「人件費等の販管費負担」 | 与件文フラグのコピペ（原因） |
| 「低収益性」 | 劣の指標が示す弱み（営業利益率） |
| 「借入金依存による安全性の低さ」 | 劣の指標が示す弱み（自己資本比率） |

---

## 補足: 類似指標を「一本化」する理由と例外

安全性には類似する指標のペアがありますが、片方に一本化して認知負荷を下げます。

| 捨てる指標 | 採用する指標 | 一本化の理由 | 例外（捨てた方を使うケース） |
| :--- | :--- | :--- | :--- |
| 流動比率 | **当座比率** | 不良在庫を含む流動比率は罠になりやすい | B/Sに棚卸資産がない、または当座資産が計算できない場合 |
| 負債比率 | **自己資本比率** | 表裏一体だが、自己資本比率の方が解答としてメジャー | 実質的に例外なし（完全に自己資本比率一択） |
| 固定比率 | **固定長期適合率** | 自己資本だけで固定資産を賄うのは中小企業に厳しすぎる | B/Sの固定負債がゼロの場合（両者が同じ値になる） |
