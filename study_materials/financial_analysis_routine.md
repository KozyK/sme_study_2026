# 経営分析の最高効率ルーチン（ヨコ倍率・指標絞り込み統合版）

事例Ⅳの第1問（経営分析）において、不要な指標を最初から捨て、残った鉄板指標の優劣を割り算なしで瞬時に判定するための「最高効率の型」です。

## 究極の作業手順（4ステップ）

### Step 1: 与件文フラグの確認（指標の事前の絞り込み）
計算に入る前に、与件文を読んで「採用する指標の当たり」をつけます。後述する**【指標と与件文フラグの紐付けマトリックス】**を参考に、定性的な強み・弱みをマークします。

### Step 2: 情報量の圧縮（上3桁化）
計算ミスと認知負荷を防ぐため、B/S・P/Lの数値の下3桁（千円単位など）を鉛筆で斜線で消し、**上3桁（百万円単位）だけで暗算する**状態を作ります。
B/Sの流動資産の横に、「当座資産（現預金＋売上債権＋有価証券）」の合計（上3桁）を手書きで足し算してメモします。

### Step 3: ヨコ倍率チェック（割り算の排除）
電卓で割り算をする代わりに、「分母の倍率（D社÷他社）」を暗算し、分子の倍率と大小比較するだけで◯×（優劣）を判定します。

| チェック対象（ベース） | 計算する基準倍率（分母） | 比較対象（分子）と判定ルール |
| :--- | :--- | :--- |
| **① 売上高ベース** | P/L「**売上高**」の倍率<br>（例：1.2倍） | **【利益】**（総利益、営業、経常）が1.2倍より大きければ◯<br>**【資産】**（棚卸、有形固定）が1.2倍より小さければ◯ |
| **② 短期安全性ベース** | B/S「**流動負債**」の倍率<br>（例：0.8倍） | **【当座資産】**の倍率が0.8倍より大きければ◯<br>*(※流動資産は見ない)* |
| **③ 長期安全性ベース** | B/S「**総資産**」の倍率<br>（例：1.1倍） | **【自己資本】**の倍率が1.1倍より大きければ◯<br>*(※負債は見ない)* |
| **④ 投資安全性ベース**<br>*(※フラグ成立時のみ)* | B/S「**自己資本＋固定負債**」<br>の倍率 | **【固定資産】**の倍率が基準より**小さければ**◯ |

### Step 4: 最終3指標の決定と精緻な計算
Step 3で◯×をつけた指標の中から、**与件文のエピソードと最も強くリンクしている3つ**を決定します。
選ばれた3つの指標についてのみ、ここで初めて電卓を使い、指定された形式で正確な数値を計算し解答用紙に記入します。

## 【コア・マトリックス】指標と「与件文フラグ」の紐付け表
「どのエピソード（記述）があれば、どの指標を採用すべきか」を完全にパターン化したテーブルです。第1問はこのテーブルとの神経衰弱ゲームです。

| 区分 | 採用すべき指標 | 採用の決め手となる「与件文の典型フラグ（気づき方）」 |
| :--- | :--- | :--- |
| **収益性** | **売上高総利益率** | **【優】**高付加価値、固定客、ブランド力、地元密着による価格維持<br>**【劣】**価格競争、外注費高騰、歩留まり悪化、原材料費の高騰 |
| **収益性** | **売上高営業利益率** | **【劣】**人件費の高止まり、多額の広告宣伝費、非効率な営業体制 |
| **収益性** | **売上高経常利益率** | **【劣】**過大な借入金による重い支払利息 |
| **効率性** | **棚卸資産回転率** | **【優】**厳格な在庫管理、IT化によるロス削減、事業間シナジー<br>**【劣】**不良在庫の滞留、見込み生産による売れ残り、品揃え過多 |
| **効率性** | **有形固定資産回転率** | **【優】**古い設備の活用、店舗の居抜き出店<br>**【劣】**過大な設備投資、機械の稼働率低下、遊休資産の存在 |
| **安全性** | **当座比率**<br>*(※流動比率の代わり)* | **【優】**手元資金が潤沢、資金繰りが安定<br>**【劣】**短期借入金への依存、現金不足、回収遅れ |
| **安全性** | **自己資本比率**<br>*(※負債比率の代わり)* | **【優】**無借金経営、内部留保が厚い、自己資金での投資<br>**【劣】**借入金過多、過大な負債による財務基盤の脆弱化 |
| **安全性** | **固定長期適合率**<br>*(※固定比率の代わり)* | **【劣】**短期借入金による無理な工場・設備投資（資金繰り悪化の危機） |

## 【コラム】流動・負債・固定比率を「捨てる」理由と例外

| 捨てる指標 | 捨てる理由（こちらを優先する理由） | 例外（使うケース） |
| :--- | :--- | :--- |
| **流動比率** | 換金性の低い不良在庫を含んでおり、資金繰りの指標として罠になりやすいため（**当座比率**を優先）。 | B/Sに棚卸資産の記載がない、または現預金等の内訳が不明で当座比率が計算できない場合。 |
| **負債比率** | 意味は自己資本比率と同じだが、解答の型としてマイナーなため（**自己資本比率**を優先）。 | 過去の事例Ⅳにおいて実質的に例外なし（自己資本比率一択）。 |
| **固定比率** | 固定資産を「自己資本だけ」で賄うのは中小企業には厳しすぎる指標のため（**固定長期適合率**を優先）。 | B/Sに固定負債（長期借入金等）が「ゼロ」の企業の場合（値が同じになるため計算が楽なこちらを使う）。 |
