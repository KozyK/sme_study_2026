# 📘 事例Ⅳ 設備投資の意思決定・NPV・ファイナンス完全攻略ガイド
〜取替投資・売却損タックスシールド・WACC・デシジョンツリーのセオリー〜

## はじめに：なぜ「設備投資NPV」が事例Ⅳの合否を決定づけるのか？

中小企業診断士2次試験の事例Ⅳにおいて、**最も配点が大きく（例年25〜30点）、最も多くの受験生が途中で計算ミスをして大量失点する最大の難所**が「設備投資の意思決定（NPV）」です。

令和6年度の試験でも、第3問として「取替投資のキャッシュフロー増加額」「NPV計算」「市場調査の情報を加味した期待値計算」が30点満点で出題されました。
多くの受験生が「問題文の条件が複雑で手が出ない」「タックスシールドや運転資本の扱いが分からない」とパニックに陥り、白紙や部分点止まりで不合格になっています。

しかし、設備投資の意思決定は、**「キャッシュフローの発生パターンを時間軸（タイムライン）で整理する手順」**さえ身体に染み込ませてしまえば、毎年出題されるパターンは驚くほど定型的です。

本書では、基礎的な概念から、取替投資、WACC（加重平均資本コスト）、デシジョンツリー、購入vsリースの比較まで、設備投資・ファイナンス理論のすべてを論理的・構造的に完全解剖します。

## 第1章：取替投資のタイムライン構築法（新規投資との違い）

### 1. 新規投資 vs 取替投資の構造的相違

| 区分 | 新規投資（設備の純増） | 取替投資（既存設備の更新） |
| :--- | :--- | :--- |
| **初期投資額（0年度期首）** | 新機械の取得価格（支出） | 新機械の取得価格 − **旧機械の売却収入** − **売却損に伴う節税額（タックスシールド）** |
| **営業キャッシュフロー** | 新設備による税引後営業利益 ＋ 減価償却費 $\times$ 税率 | **差額（増分）**の税引後営業利益 ＋ **差額（増分）**の減価償却費 $\times$ 税率 |
| **運転資本の増減** | 新規事業に伴う運転資本の純増 | 売上拡大等に伴う**増分**運転資本のみ |

取替投資の最大の特徴は、**「新機械を導入した場合」と「旧機械をそのまま使い続けた場合」の「差額（インクリメンタル・キャッシュフロー）」**で計算する点にあります。

---

### 2. タイムライン表（時系列マトリクス）の作成手順

試験用紙の余白に、以下の表を必ず最初に手書きします。

| キャッシュフロー項目 | 0年度（現在） | 1年度 | 2年度 | … | 最終年度（$n$年度） |
| :--- | :---: | :---: | :---: | :---: | :---: |
| ① 新機械の取得支出 | **−投資額** | - | - | - | - |
| ② 旧機械の売却収入 | **＋売却額** | - | - | - | - |
| ③ 旧機械売却損の節税額 | **＋節税額** | - | - | - | - |
| ④ 差額税引後営業利益 | - | ＋$CF_1$ | ＋$CF_2$ | - | ＋$CF_n$ |
| ⑤ 差額減価償却の節税額 | - | ＋$Dep_1 \times t$ | ＋$Dep_2 \times t$ | - | ＋$Dep_n \times t$ |
| ⑥ 運転資本の増減 | - | **−増加額** | - | - | **＋全額回収！** |
| **正味キャッシュフロー（合計）** | **初期投資CF** | **$NCF_1$** | **$NCF_2$** | - | **$NCF_n$** |
| 複利現価係数 | $1.000$ | $(1+r)^{-1}$ | $(1+r)^{-2}$ | - | $(1+r)^{-n}$ |
| **現在価値（PV）** | **−初期投資CF** | **$PV_1$** | **$PV_2$** | - | **$PV_n$** |

## 第2章：売却損タックスシールドの完全理解

### 1. 売却損タックスシールドとは何か？

既存設備を更新する際、帳簿価額（残存簿価）よりも低い価格で売却すると、「固定資産売却損」が発生します。

$$\text{固定資産売却損} = \text{旧機械の帳簿価額（簿価）} - \text{旧機械の売却価格}$$

この売却損が発生すると、会社全体の課税所得（利益）がその分だけ減額されます。
利益が減るということは、**「売却損 $\times$ 法人税率」の分だけ支払う税金が安く浮く**ことになります。
税金という現金の流出が減るということは、会社の手元に現金が残る、すなわち**「実質的なキャッシュイン（節税効果）」**になります。

$$\text{売却損タックスシールド} = \text{固定資産売却損} \times \text{実効税率 } t$$

#### 数値例
- 旧機械の帳簿価額：100万円
- 旧機械の売却価格：30万円
- 実効税率：30%
- **売却損**：$100 \text{ 万円} - 30 \text{ 万円} = 70 \text{ 万円}$
- **節税額（キャッシュイン）**：$70 \text{ 万円} \times 30\% = \mathbf{21 \text{ 万円}}$
- $\implies$ 旧機械を売ることで、売却代金30万円 ＋ 税金節約21万円 ＝ **合計51万円のキャッシュイン**が得られる！

## 第3章：運転資本の増減とキャッシュフロー

### 1. なぜ運転資本が増えるとキャッシュアウトなのか？

設備投資によって売上が拡大すると、売掛金（売上債権）や在庫（棚卸資産）が増加します。

$$\text{正味運転資本} = \text{売上債権} + \text{棚卸資産} - \text{仕入債務}$$

- **売掛金が増える**: 売上は計上されたが、まだ現金が入ってきていない（資金が拘束される）。
- **在庫が増える**: 材料代を支払って製品を作ったが、まだ売れていない（資金が寝てしまう）。
- **買掛金が増える**: 材料を仕入れたが、支払いを待ってもらっている（資金を借りている状態）。

したがって、**運転資本の増加は「事業資金が拘束されることによる現金の流出（マイナスCF）」**となります。

### 2. 最終年度の「運転資本回収」の鉄則

プロジェクトの最終年度には、事業を終了または定常化するため、残っていた売掛金をすべて回収し、在庫を売り切り、買掛金をすべて清算します。
拘束されていた資金が手元に戻ってくるため、**最終年度に「運転資本増加額と同額が全額キャッシュイン（プラスCF）」として計上**されます。

> **【合格者の知恵】**  
> タイムライン表を作成した瞬間に、最終年度の行に「運転資本回収 ＋○万円」と赤ペンで書いておくこと。これを足し忘れて3点失点する受験生が後を絶ちません。

## 第4章：割引計算の基本（複利現価係数 vs 年金現価係数）

### 1. 2つの現価係数の使い分け

- **複利現価係数**：$n$年後に受け取る「1円」の現在価値。
  $$\text{PV} = \frac{1}{(1 + r)^n}$$
  $\implies$ 各年度のキャッシュフロー金額が毎年異なるときに使用。
- **年金現価係数**：$n$年間にわたって「毎年同額で受け取る1円」の現在価値の合計額。
  $$\text{年金現価係数} = \sum_{k=1}^n \frac{1}{(1 + r)^k}$$
  $\implies$ 毎年のキャッシュフローが同額のとき、1年ずつ掛けて足す必要がなく、**年金額 $\times$ 年金現価係数で一発計算**できる！

## 第5章：加重平均資本コスト（WACC）とCAPM

### 1. WACCの算式と負債コストの節税効果

資本コストとは、資金の出し手（株主・債権者）から要求される期待利回り（ハードルレート）です。

$$\text{WACC} = r_d \times (1 - t) \times \frac{D}{D + E} + r_e \times \frac{E}{D + E}$$

- $D$：有利子負債（借入金・社債）の時価
- $E$：株主資本（株式）の時価
- $r_d$：負債コスト（借入金利利回り）
- $r_e$：株主資本コスト
- $t$：実効税率

#### なぜ負債コストだけに $(1 - t)$ を掛けるのか？
- 銀行に支払う「支払利息」は、損益計算書で費用（損金）として計上できるため、法人税を安くする節税効果がある。
- 株主に支払う「配当金」は、税金を支払った後の当期純利益から配分されるため、節税効果はゼロである。

### 2. 株主資本コストとCAPM（資本資産評価モデル）

$$r_e = r_f + \beta \times (r_m - r_f)$$

- $r_f$：リスクフリーレート（国債利回り）
- $r_m$：市場全体の期待収益率（TOPIX全体の平均リターン）
- $(r_m - r_f)$：市場リスクプレミアム
- $\beta$（ベータ）：市場全体が1%動いたときに、その個別株が何%敏感に動くかを示すボラティリティ指標（感応度）。

## 第6章：不確実性とデシジョンツリー・期待値（令和6年第3問設問3）

将来の業績が「好況（高業績）」になるか「不況（低業績）」になるかが不確実な場合、確率加重平均を用いて**「正味現在価値の期待値」**を算出します。

$$E(\text{NPV}) = \text{好況時NPV} \times \text{好況確率} + \text{不況時NPV} \times \text{不況確率} - \text{調査コスト}$$

### 完全情報の期待価値（EVPI: Expected Value of Perfect Information）
- 将来どちらになるかが事前に100%確実に分かる「完璧な情報（神の予言）」を手に入れるために、最大いくらまで支払ってよいか。
- $\text{EVPI} = (\text{情報がある場合の期待利益}) - (\text{情報がない場合の期待利益})$。

## 第7章：購入 vs リースの意思決定

設備を導入する際、「銀行借入で購入するか」「リース会社からリースするか」の意思決定です。

| 項目 | 借入購入 | リース契約 |
| :--- | :--- | :--- |
| **初期支出** | 機械の購入代金（マイナス） | 初期支出ゼロ |
| **毎年の支出** | なし（借入返済と利息） | **リース料の支払い（全額損金算入）** |
| **節税効果** | **減価償却費 $\times$ 税率**（＋支払利息 $\times$ 税率） | **リース料 $\times$ 税率** |
| **税引後キャッシュアウト** | 借入元利返済 − 減価償却費の節税額 | **リース料 $\times (1 - \text{税率})$** |
| **適用割引率** | 税引後借入利率 $r_d(1 - t)$ | 税引後借入利率 $r_d(1 - t)$ |

どちらの方式の方が「現在価値に割り引いたキャッシュアウトの総額が小さいか」で有利・不利を判定します。

## 第8章：耳で解く！設備投資実践ドリル

### ドリル1：売却損タックスシールド
- **問題**: 簿価500万円の機械を100万円で売却。税率30%。初年度の正味キャッシュインはいくらか？
- **解答**:
  - 売却収入：100万円
  - 売却損：$500 - 100 = 400 \text{ 万円}$
  - 売却損タックスシールド：$400 \text{ 万円} \times 30\% = 120 \text{ 万円}$
  - 正味キャッシュイン：$100 + 120 = \mathbf{220 \text{ 万円}}$

### ドリル2：WACCの計算
- **問題**: 負債400万円（利息5%）、自己資本600万円（株主資本コスト10%）、税率30%。WACCはいくらか？
- **解答**:
  - 負債比率：40%、株主資本比率：60%
  - 税引後負債コスト：$5\% \times (1 - 0.3) = 3.5\%$
  - $\text{WACC} = 3.5\% \times 0.4 + 10\% \times 0.6 = 1.4\% + 6.0\% = \mathbf{7.4\%}$
